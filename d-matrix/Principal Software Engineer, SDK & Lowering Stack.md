## Role: Principal Software Engineer, SDK & Lowering Stack

### Responsibilities

- Architect and develop the kernel authoring SDK targeting the novel Corsair dataflow architecture.
- Champion software engineering best practices across the team by establishing robust CI/CD pipelines, driving automated testing, and enforcing rigorous code review processes.
- Build intuitive, domain-specific APIs and determine optimal boundaries between kernel developers and compiler teams.
- Develop tools for kernel authoring and modeling lowering flows.
- Lead and mentor junior engineers, fostering technical excellence, accountability, and collaborative problem-solving.
- Apply systems engineering expertise to understand complex hardware-software interactions and implement solutions across the software stack.
- Take ownership of end-to-end solution delivery, including:
  - Stakeholder interaction.
  - Requirements engineering.
  - Design documentation.
  - Implementation and debugging.
  - Deployment.
- Build and scale software deliverables within tight development timelines.

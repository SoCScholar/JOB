## Role: Staff Software Engineer, SIMD Kernels

### Role Overview

As a member of the SIMD Kernels team, the engineer will help productize the software stack for d-Matrix's AI compute engine.

The role involves developing, enhancing, and maintaining software kernels for machine learning operators, including:

- Softmax.
- Layer normalization.
- Activation functions.

The engineer will also develop solutions that make the SDK intuitive for developers and provide tools for performance analysis.

The ideal candidate should have experience building software kernels for modern hardware architectures and understand how to map algorithms and AI-framework computational graphs onto specialized architectures.

The role requires working across the full software toolchain and navigating hardware-software co-design trade-offs while delivering high-quality software in a fast-moving development environment.

---

## Responsibilities

- Develop, enhance, and maintain software kernels for machine learning operators.
